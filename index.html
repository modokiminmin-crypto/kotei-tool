          未連携
          常時連携(Apps Script)未設定
          常時連携をおすすめする理由: Googleのログインは1時間で切れるが、常時連携なら切れない。開くだけで自動で同期され、赤いバナーも出ない。
          しなくても使える: 都度連携でも予定は同期される。切れている間の今日の記録は、次に連携したときに自動で反映される。
          設定の手順を見る
          つなぎたいカレンダーのGoogleアカウントで、パソコンでやるのがおすすめ。
          1. そのアカウントで script.google.com を開き、「新しいプロジェクト」を作る
          2. 最初のコードを全部消し、下の「コードをコピー」で貼り付け、保存ボタン(フロッピーのマーク)を押す
          3. 左の「サービス」の+から Google Calendar API を追加する
          4. 関数選択で _scope を選んで「実行」し、許可する(「安全でないページ」と出ても「詳細」から進める)
          5. 「デプロイ」→「新しいデプロイ」→ 左上の歯車から「ウェブアプリ」。実行するユーザーは自分、アクセスできるユーザーは全員にしてデプロイ
          6. 出てきたURLを下に貼り付けて「保存して接続する」
          ほかの端末・ホーム画面(かんたんな方法):
          1. 普通にホーム画面に追加する
          2. 「他の端末用のリンクをコピー」で作ったリンクを、その端末にコピーしておく
          3. ホーム画面のアプリを開き、「カレンダー」タブの常時連携で「クリップボードから取り込む」を押す
          iPhoneでは、Safariとホーム画面のアプリはデータが別なので、それぞれで1回必要。
          うまくいかないとき: Safariを機内モードにしてリンクを開く(表示はされないが問題ない)→ホーム画面に追加→機内モードを解除。iPhoneがホーム画面に登録するURLの都合で、通信できる状態だと設定が消えることがあるため。
          常時連携が有効。

            実行ログ(割り込み含む)

              通知設定(この端末)

              PCとスマホで、それぞれ別に設定できる。
              LINE通知の設定手順(1回だけ)
              1. 上の「新しいコードをコピー」を押し、Apps Scriptのコードを全部消して貼り付けて保存。(いまの接続キーが入ったコードになる)
              2. Apps Script左の歯車「プロジェクトの設定」→ いちばん下「スクリプト プロパティ」で2つ追加。LINE_TOKEN=長期チャネルアクセストークン、LINE_USER=自分のユーザーID(わからなければ省略可。その場合は公式アカウントの友だち全員に送る)。※ここ以外(このアプリ・チャット)には貼らない。
              3. 上のメニューで関数 kSetup を選んで「実行」。許可を求められたら許可。(1分ごとの自動チェックが作られる)
              4. 「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」。
              5. 関数 kTest を実行して、LINEにテストが届けばOK。
              6. このアプリで「LINEにも送る」をオン。
              この通知はアプリを開いている間だけ動く。閉じている間やロック中は鳴らない。「定期的に声をかける」は、タスクの実行中に、選んだ間隔で「まだ続いてる?終わっていれば終了を押そう」と知らせる(終了か中断を押すまでくり返す)。閉じていても欲しい予定は、LINE通知(上の設定)を使う。LINEには、その日にアプリを開いたとき見えていた予定が登録されるので、1日1回はアプリを開く必要がある。時刻指定の通知とスヌーズはアプリ内だけ。
